# Contributing

1. Create a branch from `main`.
2. Never commit `.env`, restricted records, raw imagery or model binaries.
3. Add provenance and quality fields for every new source.
4. Add a migration for schema changes.
5. Run backend, ETL and frontend tests.
6. Confirm the UI does not confuse estimated, synthetic, predicted and observed data.
7. Open a pull request describing data licences and operational impact.
